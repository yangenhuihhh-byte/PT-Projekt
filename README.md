# PT Projekt

Surface height prediction using U-Net.

## Project Structure

```
scripts/
    prepare_dataset.py
    train.py
    predict.py
```

## Environment

- Python
- PyTorch
- CUDA

## Model

- U-Net
- Patch size: 128×128
- Stride: 192
- Epochs: 100

## Dataset

Alicona microscope dataset
